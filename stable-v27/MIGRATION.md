# Diktat Player en GitHub

Esta rama contiene la aplicación completa y se publica directamente desde GitHub Pages, sin descargar el código desde Sites.

## Versiones conservadas

- Versión 20: aplicación principal completamente alojada en GitHub.
- Versión 19: copia ejecutable en `stable-v19/`.
- Versión 14: respaldo independiente conservado en Sites.

La rama `backup/pre-migration-v19` conserva además el workflow híbrido anterior.
